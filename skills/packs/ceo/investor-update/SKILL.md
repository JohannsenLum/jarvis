# Investor update

## Procedure
1. Read this month's `metrics/`, `decisions/`, hiring in `team/`, and `log.md`.
2. Draft `board-investors/updates/YYYY-MM.md`: TL;DR, key metrics table (vs last month), highlights,
   lowlights, what we learned, asks (intros, hires, advice).
3. Flag any metric that's missing instead of estimating it. Never send without a yes.

# Update brag doc

## Procedure
1. Turn what the user said into one row: date, what, impact (numbers if any), evidence (link or page).
2. Ask one question if impact is missing: "What changed because of it?" (skippable).
3. Add the row to the top of `work/<company>/wins.md`; log it.
